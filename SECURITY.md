# Security policy

## Supported versions

Security fixes go into `main` and the next release. Please keep to the latest release.

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately through GitHub: open the repository's
[Security tab](https://github.com/hubra-app/hubra-cli/security) and click **Report a vulnerability**.
Include:

- what is affected and the version, image tag or commit;
- steps to reproduce, or a proof of concept;
- what an attacker could do with it.

We aim to answer within a week and to ship a fix as soon as we can. We credit you in the release
notes unless you'd rather stay anonymous.
